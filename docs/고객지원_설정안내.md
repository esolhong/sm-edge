# 고객지원(자료실·회원·고객문의) 설정 안내

홈페이지는 지금처럼 GitHub Pages에서 그대로 운영하고, **회원가입·로그인·회원 정보·문의 저장·자료 파일 보관**만 구글의 **Firebase**에 맡깁니다.
아래 순서대로 한 번만 설정하면 됩니다. (약 30분, 모두 hsp@sm-edge.com 구글 계정으로 진행)

## 이렇게 동작합니다

| 기능 | 어디에 저장 | 누가 볼 수 있나 |
|---|---|---|
| 회원 정보 (이름·연락처·이메일·회사명) | Firestore (서울) | 본인과 관리자만 |
| 고객문의 | Firestore (서울) | 작성 회원 본인과 관리자만 (비공개) |
| 소프트웨어·일반 자료 | Storage | 누구나 내려받기 |
| 도면 (PDF·DXF·STEP) | Storage `members/` 폴더 | 보유기간이 남은 회원과 관리자만 |
| 3년 보관 | 각 기록의 `expireAt`(만료일) | 만료 전 안내 메일 → 연장 또는 관리자가 삭제 |

- 관리자 페이지: `https://sm-edge.com/admin.html` (hsp@sm-edge.com 구글 로그인)
  - 고객문의 확인·답변, 회원 목록·엑셀 내려받기, 자료 올리기·삭제
- 회원은 "내 정보"에서 정보 수정, 보유기간 3년 연장(재동의), 탈퇴를 직접 할 수 있습니다.

## 예상 비용

- **회원·문의(Firestore), 로그인(Authentication)**: 무료 사용량(저장 1GB, 하루 읽기 5만 회) 안에서 충분 → 0원
- **자료 파일(Storage)**: 2024년 10월부터 구글 정책상 Storage를 쓰려면 "Blaze(사용한 만큼 결제)" 요금제로 바꾸고 카드를 등록해야 합니다.
  저장 위치를 **us-central1** 로 고르면 저장 5GB, 다운로드 월 100GB까지 무료라서 이 정도 규모면 사실상 **0원**입니다.
  (도면·소프트웨어 파일은 개인정보가 아니므로 미국 위치여도 문제없습니다.)
- 안전장치로 **예산 알림(예: 월 1만 원)** 을 꼭 걸어 둡니다.
- 큰 설치 파일은 구글 드라이브 공유 링크로 올려도 됩니다. (관리자 페이지 "외부 링크" 칸)

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → hsp@sm-edge.com 으로 로그인
2. **프로젝트 만들기** → 이름 `smartedge-web` → Google 애널리틱스는 **사용 안 함** → 만들기

### 2. 웹 앱 등록 (연결 값 받기)
1. 프로젝트 개요 화면에서 **`</>` (웹)** 아이콘 클릭 → 앱 이름 `홈페이지` → 등록 (Hosting 체크는 하지 않음)
2. 화면에 나오는 `firebaseConfig = { apiKey: ..., ... }` 부분을 **복사해서 Claude에게 보내 주세요.**
   공개되어도 괜찮은 값이며, Claude가 `assets/js/firebase-config.js` 에 넣어 드립니다.

### 3. 로그인 방식 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **이메일/비밀번호** 사용 설정 → 저장
3. **새 제공업체 추가 → Google** 사용 설정 → 지원 이메일 hsp@sm-edge.com → 저장 (관리자 로그인용)
4. **설정** 탭 → **승인된 도메인** → `sm-edge.com`, `www.sm-edge.com` 추가
5. (선택) **템플릿** 탭 → 언어를 한국어로 바꾸면 비밀번호 재설정 메일이 한국어로 갑니다.

### 4. 회원·문의 저장소(Firestore) 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: **asia-northeast3 (서울)** → **프로덕션 모드**로 시작
3. **규칙** 탭 → 내용을 모두 지우고 저장소의 `firebase/firestore.rules` 내용을 붙여 넣기 → **게시**

### 5. 자료 파일 저장소(Storage) 만들기
1. 왼쪽 아래 **요금제 업그레이드 → Blaze** 선택 → 카드 등록 → **예산 알림 금액(예: 10,000원)** 설정
2. **빌드 → Storage → 시작하기** → 위치 **us-central1** → **프로덕션 모드**
3. **규칙** 탭 → `firebase/storage.rules` 내용을 붙여 넣기 → **게시**
   (Firestore 회원 정보를 확인해도 되는지 묻는 창이 뜨면 **허용**)

### 6. 3년 보관기간 관리 (따로 설정할 것 없음)
자동 삭제는 쓰지 않습니다. 관리자 페이지 **회원** 탭에서 다음 순서로 관리합니다. (한 달에 한 번 확인 권장)
1. **만료 30일 이내** 를 눌러 대상 회원을 확인 → **선택한 회원에게 연장 안내 메일** 버튼으로 메일 보내기
2. 회원이 "내 정보 → 3년 연장"을 누르면 보유기간이 자동으로 늘어납니다.
3. 만료일이 지나도 연장하지 않은 회원은 **만료됨** 목록에서 **삭제**합니다. (법상 보유기간이 끝난 정보는 지체 없이 파기해야 합니다)
4. 보관 기한(3년)이 지난 고객문의는 **고객문의 → 보관기한 지남** 에서 삭제합니다.

> 만료일이 지나면 그 회원은 연장하기 전까지 도면을 내려받을 수 없습니다.
> 회원 정보를 삭제한 뒤 남은 로그인 계정은 Firebase 콘솔 Authentication 화면에서 같은 이메일을 찾아 지워 주세요.

### 7. 확인
- `support.html` 에서 회원가입 → 도면 내려받기가 되는지
- `inquiry.html` 에서 문의 작성 → `admin.html` 에서 보이는지

## 운영 팁
- **새 문의 알림**: 지금은 관리자 페이지에서 확인합니다. 메일 알림이 필요하면 Firebase "Trigger Email" 확장 기능으로 추가할 수 있습니다(추가 설정 필요).
- **답변**: 관리자 페이지에서 답변을 저장하면 회원은 "내 문의 내역"에서 볼 수 있고, 비회원 문의는 "이메일로 답장" 버튼으로 메일을 보내 주세요.
- **스팸**: 문의 양식에 기본 스팸 방지가 들어 있습니다. 스팸이 많아지면 reCAPTCHA(App Check)를 추가합니다.
- **개인정보처리방침**: `privacy.html`. 내용(위탁, 보유기간 등)이 바뀌면 함께 고쳐야 합니다.
- **도면 링크 공유 주의**: 회원이 내려받을 때 생기는 파일 주소를 다른 사람에게 그대로 전달하면 그 사람도 열 수 있습니다. 유출이 걱정되는 도면은 관리자 페이지에서 삭제 후 다시 올리면 이전 주소는 더 이상 열리지 않습니다.
