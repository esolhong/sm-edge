PCB 거버뷰어

PCB 업체에 보내는 거버 파일을 그대로 열어 레이어별로 확인하고, SMT 실장에 필요한 부품 좌표와 파트리스트를 바로 뽑아 주는 도구입니다. 올린 파일은 서버로 전송되지 않고 내 PC의 브라우저 안에서만 처리됩니다.

주요 기능

  • 거버 ZIP 통째로 열기: 동박, 마스크, 실크, 드릴, 외곽 레이어를 켜고 끄며 확인
  • 어레이(연배열) 보드를 자동으로 나눠 보드별로 표시
  • 부품 중심 좌표 추출, 원점(ORG) 직접 지정, TOP/BOTTOM 구분
  • 레퍼런스·값·마킹을 표에서 편집하고 파트리스트 CSV로 저장
  • 회로도·실장 사진·PDF를 옆에 띄워 놓고 대조하며 입력

지원 파일

거버 RS-274X / RS-274DZIP 묶음Excellon 드릴ODB++IPC-356 넷리스트PDF·사진 (참조용)

사용 방법

  1. 새 창에서 열기를 눌러 뷰어를 엽니다.
  2. 불러오기에서 거버 ZIP이나 ODB++ 파일을 고르거나 화면에 끌어다 놓습니다.
  3. 레이어와 보드를 확인하고, 필요하면 ORG 원점 지정으로 좌표 기준을 잡습니다.
  4. 부품 좌표 · 파트리스트 표에서 레퍼런스와 값을 확인·수정합니다.
  5. 저장에서 SMT 좌표와 파트리스트 CSV를 내려받습니다.
새 창에서 열기

거버에는 레퍼런스 번호(R1, C3 등)가 없는 경우가 많습니다. 이때는 회로도를 보며 레퍼런스를 채워 주세요. 사진·PDF에서 부품을 자동으로 읽어 내는 기능은 홈페이지판에는 포함되어 있지 않습니다. 넓은 화면의 PC에서 쓰기를 권장합니다.
