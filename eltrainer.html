PCB GERBER VIEWER

PCB 거버뷰어

PCB 업체에 보내는 거버 파일을 그대로 열어 레이어별로 확인하고, SMT 실장에 필요한 부품 좌표와 파트리스트를 바로 뽑아 주는 도구입니다. 올린 파일은 서버로 전송되지 않고 내 PC의 브라우저 안에서만 처리됩니다.

주요 기능

  • 거버 ZIP 통째로 열기: 동박, 마스크, 실크, 드릴, 외곽 레이어를 켜고 끄며 확인
  • 어레이(연배열) 보드를 자동으로 나눠 보드별로 표시
  • 부품 중심 좌표 추출, 원점(ORG) 직접 지정, TOP/BOTTOM 구분
  • 레퍼런스·값·마킹을 표에서 편집하고 파트리스트 CSV로 저장
  • 회로도·실장 사진·PDF를 옆에 띄워 놓고 대조하며 입력

지원 파일

거버 RS-274X / RS-274DZIP 묶음Excellon 드릴ODB++IPC-356 넷리스트PDF·사진 (참조용)

사용 방법

  1. 새 창에서 열기를 눌러 뷰어를 엽니다.
  2. 불러오기에서 거버 ZIP이나 ODB++ 파일을 고르거나 화면에 끌어다 놓습니다.
  3. 레이어와 보드를 확인하고, 필요하면 ORG 원점 지정으로 좌표 기준을 잡습니다.
  4. 부품 좌표 · 파트리스트 표에서 레퍼런스와 값을 확인·수정합니다.
  5. 저장에서 SMT 좌표와 파트리스트 CSV를 내려받습니다.
새 창에서 열기

거버에는 레퍼런스 번호(R1, C3 등)가 없는 경우가 많습니다. 이때는 회로도를 보며 레퍼런스를 채워 주세요. 사진·PDF에서 부품을 자동으로 읽어 내는 기능은 홈페이지판에는 포함되어 있지 않습니다. 넓은 화면의 PC에서 쓰기를 권장합니다.

GERBER CNC

일렉트레이너 거버CNC

거버 데이터와 DXF 파일을 이용한 지그 제작과 판재 가공을 위한 CNC 조각기용 G-code 생성기입니다. PCB 거버나 AutoCAD 도면에서 외곽(자삽바 포함)과 LED 홀을 골라 Mach3용 G-code와 DXF를 만듭니다. 공구 경로를 화면에서 시뮬레이션해 보고 내려받을 수 있습니다. 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

주요 기능

  • 어레이 거버에서 PCB 외곽과 LED 홀(두 리드 중간점) 자동 추출
  • DXF·DWG 도면의 외곽·홀 불러오기, 홀 간격·지름 치수 표시
  • 사각형·원·홀 그리기, 회전, 어레이(반복 배열), 가공 원점 지정
  • 엔드밀 지름·재료 두께·절입·이송 속도·브리지 설정, 작업 종류별 기본값 저장
  • G-code 시뮬레이션, 기존 NC 데이터 불러와 보기

지원 파일

거버 ZIPDXFDWGNC · TAP (Mach3)

사용 방법

  1. 새 창에서 열기를 눌러 거버CNC를 엽니다.
  2. 불러오기에서 거버 ZIP이나 DXF·DWG 도면을 엽니다.
  3. 가공할 외곽과 LED 홀을 켜고 끄고, 필요하면 어레이와 원점을 정합니다.
  4. 오른쪽에서 재료·공구 값을 확인하고 시뮬레이션으로 경로를 확인합니다.
  5. 저장에서 G-code(.tap)와 DXF를 내려받습니다.
새 창에서 열기

만든 G-code는 실제 가공 전에 반드시 시뮬레이션과 공중 가공(드라이런)으로 확인해 주세요. PDF 도면에서 치수를 자동으로 읽는 기능은 홈페이지판에는 포함되어 있지 않습니다. 넓은 화면의 PC에서 쓰기를 권장합니다.

WIRING SIMULATOR

배선검사 시뮬레이터 (전기기능장)

전기기능장 실기 공개문제의 기구 배치, 나사 체결, 배관, 배선을 화면에서 그대로 연습하고, 결선 검사로 오결선·미결선 위치를 바로 확인하는 시뮬레이터입니다. 홈페이지 회원은 설치 없이 브라우저에서 무료로 웹 체험판을 실행할 수 있습니다.

주요 기능

  • 제어함 기구 배치, 이격·높이 점검, 나사 체결
  • 전선 색별 배선, 단자대 라벨, 케이블 타이, 사용량 표시
  • 배관 작업판: 배관·커넥터·새들, 현장 기구 부착과 배선
  • 결선 검사: 오결선·미결선 단자를 작업판에 바로 표시
  • 작업 저장·불러오기, 완료 시간 기록

웹 체험판과 정품

웹 체험판: 공개문제 1 · 15일정품(Windows PC): 공개문제 1~101년 라이선스 50,000원

사용 방법

  1. 새 창에서 열기를 누르고 홈페이지 회원으로 로그인합니다(회원 무료). 처음에는 내려받기(약 100MB)에 시간이 조금 걸립니다.
  2. 공개문제 1을 고르고 분필 작업, 기구 배치, 나사 체결 순서로 진행합니다.
  3. 배선을 마치면 오른쪽 위 결선 검사로 틀린 곳을 확인합니다.
  4. 도면은 큐넷 자료실의 공개문제 PDF를 따로 열어 놓고 보며 작업합니다.
